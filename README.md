# CCMP Lesson 1.1

Interactive click-through experience for **Case Study: Implementing a New HR Information System**.

The lesson copy is taken directly from Lesson 1.1 of `CCMP - Module 1 .docx`. The experience uses progressive reveals, a four-principle exploration drawer, outcome sequencing, discussion prompts, and six custom CertSprints-style illustrations.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
